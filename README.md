🏢 Digital Maintenance Tracker – Apartment Management System

📌 Overview  
Digital Maintenance Tracker is a full-stack web application developed for managing apartment/building maintenance activities digitally. The system helps residents raise maintenance requests, technicians update service status, and admins manage users and assignments efficiently.

✨ Features

👤 Resident
• Register/Login  
• Raise maintenance/service requests  
• Track request status  
• View maintenance history  

🛠️ Technician
• View assigned requests  
• Update work progress  
• Mark requests as completed  

🧑‍💼 Admin
• Manage users  
• Assign technicians  
• Monitor all maintenance requests  
• Control overall system workflow

🚀 Installation & Setup

📥 Clone Repository

git clone https://github.com/Vinay-1709/Digital-Maintenance-Tracker-Apartment-Management-System.git

⚙️ Backend Setup

cd backend
npm install
npm start

Backend runs on:
http://localhost:3000

🎨 Frontend Setup

cd frontend
npm install
ng serve

Frontend runs on:
http://localhost:4200

🗃️ Database Setup

• Open MySQL  
• Create database  
• Import SQL file  
• Update database credentials in backend configuration
